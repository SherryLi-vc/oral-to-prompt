用户要把口语命令、草稿或一个角色/岗位名改写成固定六段式系统提示词时使用（通用提示词优化；「私人秘书」只是可选情景代入）。 触发场景：提到「提示词」「系统提示词」「prompt」「system prompt」「优化 prompt / 优化提示词」「改写命令 / 改写口令」「把这段话写成提示词」， 或「写一段关于 xxx（角色/岗位）的提示词」「帮我写个 system prompt，角色是 xxx」「给 xxx 助手写提示词」「write a system prompt for a senior xxx」等。 点名角色/岗位时先检索「资深且优秀的 xxx」画像（知识/能力/特质/职责边界/常见场景，标【来源】/【推断】，禁止无搜捏造），再归档进六段。点名角色但场景可分叉时先短问锁死再调研；任务背景写执行场景不写要提示词；交付前跑 gate_final。 不编造用户事实、不改原意、不执行命令本身；中英跟随。 不同于 socratic-coach（问清自己的问题）、grill-me（烤方案）、send-on-behalf（外发消息），也不是「现在就扮演这个角色干活」。 可由 /提示词优化 或 /改写命令 触发。
